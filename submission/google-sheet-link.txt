STEP-BY-STEP SETUP & SYNCHRONIZATION:
--------------------------------------------------------------------------------

1. CREATE A TARGET SPREADSHEET:
   - Go to https://sheets.new and create a new blank Google Sheet.
   - Name it "PortfolioOS - Career Database Sync".
   - Copy the Spreadsheet ID from the URL:
     https://docs.google.com/spreadsheets/d/<SPREADSHEET_ID>/edit

2. CONFIGURE SERVICE ACCOUNT CREDENTIALS:
   - In Google Cloud Console (https://console.cloud.google.com/), enable the
     "Google Sheets API".
   - Create a Service Account and download its JSON key file.
   - Save the JSON key file locally (e.g., as `google-credentials.json` in the
     server root — this file is ignored by Git in `.gitignore`).
   - Share your Google Sheet with the Service Account email address with
     "Editor" permissions.

3. CONFIGURE ENVIRONMENT:
   In `.env`:
     GOOGLE_SERVICE_ACCOUNT_KEY_PATH=./google-credentials.json
     GOOGLE_SPREADSHEET_ID=<YOUR_REAL_SPREADSHEET_ID>

4. EXECUTE LIVE EXPORT:
   - In PortfolioOS, open "Google Sheets" (`http://localhost:5173/sheets`).
   - Verify the Service Account email and Spreadsheet ID appear as "Configured".
   - Click "Export All Tabs to Sheets".
   - PortfolioOS will create and populate 7 dedicated worksheet tabs:
       * Profile
       * Education
       * Skills
       * Projects
       * Experience
       * Certifications
       * Achievements
     with stable database UUIDs in Column A to prevent duplicate rows.
   - The sync event will appear with status SUCCESS in the Synchronization Audit Logs.
