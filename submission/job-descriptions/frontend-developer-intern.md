# Job Description: Frontend Developer Intern

**Company:** Vanguard Digital Labs  
**Role:** Frontend Developer Intern  
**Location:** San Francisco, CA (Hybrid)  
**Term:** Summer 2025 / Academic Year Internship  
**Department:** Web Platform & UI Architecture  

---

## About Vanguard Digital Labs
Vanguard Digital Labs engineers mission-critical enterprise telemetry platforms and responsive web applications. Our engineering team prioritizes accessible component architectures, sub-millisecond render performance, and seamless state orchestration.

---

## Role Overview
As a Frontend Developer Intern, you will work directly with senior frontend architects to build and maintain high-performance user interfaces, expand our internal component design library, and optimize client-side data rendering.

---

## Key Responsibilities
- Develop modular, reusable, and accessible UI components conforming to WCAG 2.1 AA standards.
- Build responsive dashboards and interactive data visualization workflows using React and TypeScript.
- Implement efficient client-side data fetching and state caching using RESTful APIs and modern frontend tooling.
- Author comprehensive component tests using modern testing frameworks (Vitest, React Testing Library).
- Participate in weekly sprint rituals, PR code reviews, and architectural design evaluations.

---

## Required Qualifications & Skills
- **Languages:** Strong foundation in TypeScript, JavaScript (ES6+), HTML5, and CSS3.
- **Frameworks & Libraries:** Practical hands-on experience with React (v18+) and modern build tooling (Vite).
- **Styling:** Fluency in responsive design principles and utility-first styling with Tailwind CSS.
- **Testing & Quality:** Familiarity with unit and integration testing workflows using Vitest or Jest.
- **Tools:** Proficiency with Git, GitHub branching workflows, and command-line development environments.
- **Education:** Currently pursuing a Bachelor's or Master's degree in Computer Science, Software Engineering, or a related technical discipline with strong academic standing.

---

## Preferred / Bonus Qualifications
- Prior experience designing or contributing to an open-source component library or design system.
- Understanding of performance profiling (Core Web Vitals, re-render avoidance, hardware-accelerated CSS).
- Active personal portfolio or GitHub profile showcasing clean documentation, live demos, and test suites.
